# Map geometry

`ne_110m_land.json` is Natural Earth 1:110m land geometry, downloaded from
https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_land.geojson .
Natural Earth data is public domain: https://www.naturalearthdata.com/about/terms-of-use/ .

Geometry is bundled locally; displaying the map does not call an external map service.
Region markers are approximate representative locations, not AWS facility coordinates.
